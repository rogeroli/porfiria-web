# Porfiria Web

Frontend web do Porfiria Academy.

## Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Shadcn UI
- React Query
- React Hook Form
- Zod
- Axios

## Setup Local

Copie o arquivo de ambiente:

```bash
cp .env.example .env
```

Instale as dependências:

```bash
npm install
```

Inicie o servidor de desenvolvimento:

```bash
npm run dev
```

A aplicação ficará disponível em:

```text
http://localhost:3001
```

## Qualidade

Antes de concluir uma implementação, execute:

```bash
npm run lint
npm run build
```
